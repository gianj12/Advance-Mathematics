# Advanced Mathematics: Interactive Graphing Guide

Sine, Cosine and Tangent for Our Lady of the Sacred Heart College of Guimba, Inc.

Graph models by Daileg, Gian Jim; Villano, Gian; Goh, Wenkai — built in GeoGebra and recreated here.

## Features
- Welcome, Vision, Mission, Core Values, and learner log-in (name, grade level, section)
- Sine, Cosine and Tangent pages with interactive graphs
- Practice questions and a 15-question Final Check with certificate
- XP, levels, badges, and light/dark mode

It is a single static file (`index.html`). No build step needed.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `trig-guide`), set to **Public**.
2. Click **Add file → Upload files**, drag in `index.html`, `README.md` and `.nojekyll`, then **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, then **Save**.
4. After about a minute your link will be:
   `https://YOUR-USERNAME.github.io/trig-guide/`

## Or with git
```bash
git init
git add .
git commit -m "Add trigonometry graphing guide"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/trig-guide.git
git push -u origin main
```
Then do step 3 above.
